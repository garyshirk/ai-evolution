# AI Evolution

## Project purpose

This project is an agent-based evolutionary simulation application with a browser-based user interface. Develop it incrementally, starting with simple, rule-based software agents and gradually introducing individual selection, cooperation, competition between groups, and eventually cultural evolution.

## Development guidelines

1. Keep the simulation engine independent of the user interface.
2. Favor simple, readable, modular code.
3. Develop incrementally through clearly defined releases.
4. Write automated tests for simulation logic.
5. Avoid unnecessary dependencies and architectural complexity.
6. Document significant architectural decisions.
7. Before implementing major features, explain the proposed approach and wait for the user's approval.
8. Do not introduce LLM-powered simulation agents unless explicitly requested. Initial agents must be simple, rule-based software entities.
9. Use Python for the simulation engine unless the user explicitly agrees to a different language.

## Completion reports

Always present the final task report in a plain text code block so the user can easily copy and paste it.
